# Client template

Copy this directory to `clients/<client-id>/` to onboard a client, then follow
`.claude/skills/client-onboarding/SKILL.md`.

Replace this README with:

- **Client context** — who they are, which systems agents act on, environments.
- **Accepted warnings** — each validator warning the client accepts, who
  accepted it, and when.
- **Open questions** — anything the profile assumes that the client has not
  confirmed.
- **Unmet requirements** — what the client needs that ARC does not provide
  today (see `docs/harness/CLIENTS.md`, "What a profile does not prove").
